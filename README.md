# Playwright TypeScript Automation Framework

## Overview

A Playwright automation framework developed using TypeScript, Page Object Model (POM), reusable utilities, and data-driven testing techniques.

The framework demonstrates automated validation of dynamic grid data, login workflows, and reusable test architecture.

## Tech Stack

* Playwright
* TypeScript
* Node.js
* Page Object Model (POM)
* JSON Test Data
* HTML Reporting

## Features

* Page Object Model Design Pattern
* Dynamic Grid Validation
* Reusable Utility Functions
* External Test Data Management
* Cross-Browser Support
* Playwright HTML Reports
